# whimsial.github.io

Personal academic website of Andrii Iakovliev — built with
[Jekyll](https://jekyllrb.com/) and deployed to GitHub Pages.

Live at <https://whimsial.github.io>.

## How it works

- **Profile** (name, role, affiliation, contact links) lives in the `author:`
  block of [`_config.yml`](_config.yml).
- **Publications** are pulled automatically from ORCID and a hand-maintained
  BibTeX file — see below.
- **Research projects** are listed in [`_data/projects.yml`](_data/projects.yml).
- **Home-page news** items are in [`_data/news.yml`](_data/news.yml).
- **Pages** are markdown files in [`_pages/`](_pages/).

## Adding a page

Create one markdown file in `_pages/`. For example, `_pages/teaching.md`:

```markdown
---
title: Teaching
nav: true        # show it in the top navigation
nav_order: 5     # position in the nav (Home is first)
lead: "An optional one-line summary shown under the title."
---

Your page content in **markdown**.
```

The file is published at `/teaching/` and, because `nav: true`, appears in the
navigation automatically. Omit `nav` to publish a page without a nav link.

## Publications

The publication list is generated by
[`scripts/fetch_publications.py`](scripts/fetch_publications.py), which:

1. pulls the authoritative list of works from **ORCID**
   (`0000-0003-4031-0073`);
2. merges in any extra entries from
   [`_bibliography/extra.bib`](_bibliography/extra.bib) — use this for items
   ORCID misses, such as conference papers, posters or talks;
3. enriches every work that has a DOI with author lists and venue (Crossref)
   and abstracts and open-access PDF links (Semantic Scholar);
4. writes [`_data/publications.yml`](_data/publications.yml), which the site
   renders.

It runs **weekly** via the
[`update-publications`](.github/workflows/update-publications.yml) GitHub Action
(and can be triggered manually from the Actions tab). To refresh locally:

```bash
pip install -r scripts/requirements.txt
python scripts/fetch_publications.py
```

## Running locally

Requires Ruby and [Bundler](https://bundler.io/).

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000>.

## Deployment

The site is built and deployed by the
[`deploy`](.github/workflows/deploy.yml) GitHub Action on every push to
`master`.

> **One-time setup:** in the repository **Settings → Pages**, set
> **Source** to **GitHub Actions**.
